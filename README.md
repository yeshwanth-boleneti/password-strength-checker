# Password Strength Checker 🔐

A simple Python script that evaluates password strength based on common security rules.

---

## 📌 Features
- Checks minimum password length  
- Detects uppercase letters  
- Detects digits  
- Detects special characters  
- Classifies passwords as **Weak**, **Medium**, or **Strong**

---

## 🧠 Logic Used
The strength is determined using:
- Length ≥ 8 characters
- Presence of:
  - Uppercase letters
  - Numbers
  - Special characters

---

## ▶️ How to Run

```bash
python main.py
````

You’ll be prompted to enter a password, and the script will return its strength.
